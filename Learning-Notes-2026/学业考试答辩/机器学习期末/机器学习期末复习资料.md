# 第 1 章 机器学习简介

> 以下为 OneNote 笔记原文转录。

## 1.1 机器学习模型思维导图
机器学习模型分为：
- **有监督模型**
  - 单模型
    - 线性模型：线性回归、逻辑回归、Lasso、Ridge、LDA
    - k 近邻
    - 决策树：ID3、C5.0、CART
    - 神经网络：感知机、神经网络
    - 支持向量机：线性可分、线性不可分
  - 集成学习
    - Boosting：GBDT、AdaBoost、XGBoost、LightGBM、CatBoost
    - Bagging：随机森林
- **无监督模型**
  - 聚类：kmeans、层次聚类、密度聚类
  - 降维：PCA、SVD
- **概率模型**
  - 推断法：EM 算法、MCMC
  - 判别分析：朴素贝叶斯、贝叶斯网络、CRF
  - 概率图：最大熵模型、HMM

（注：有真实结果/标签的是有监督模型，分为分类和回归。）

## 1.2 模型的类别
模型的类别有两种：
- **概率模型** (Probabilistic Model) 和 **非概率模型** (Non-Probabilistic Model)。
  1. 概率模型：决策树、朴素贝叶斯等。
  2. 非概率模型：感知机、支持向量机、K-means 以及神经网络等。
- 可按照判别函数线性与否分成 **线性模型** 与 **非线性模型**：
  1. 线性模型：感知机、线性支持向量机、K-means
  2. 非线性模型：核支持向量机、神经网络

## 1.3 损失函数
1. **0-1 损失函数** (0-1 Loss Function)
   $$L(Y,f(x))=\begin{cases}1, & Y\neq f(x)\\ 0, & Y=f(x)\end{cases}$$
2. **平方损失函数** (Quadratic Loss Function)
   $$L(Y,f(x))=(Y-f(x))^2$$
3. **绝对损失函数** (Absolute Loss Function)
   $$L(Y,f(x))=|Y-f(x)|$$

## 1.4 优化算法 & 模型评估指标
**(3) 优化算法**
- 算法指的是模型学习中的具体计算方法，也叫解决问题的过程。一般来说，基于参数模型构建的统计学习问题都是最优化问题。
- 现有的优化方法主要有：梯度下降法、牛顿法、拟牛顿法等。

**(4) 模型评估指标**
- **准确率**：模型对整个样本的判定能力，即能将好样本预测为好、坏样本预测为坏的能力。
  $$准确率 = \frac{预测正确的样本数}{样本总数}$$
- 范围在 0-1 之间，值越大越好。

## 【考点补充】（帮助考试，非笔记原文）

### 1.5 基本术语（高频）
| 术语 | 含义 |
|---|---|
| 样本 / 示例 | 一个对象的描述，如 `(色泽=青绿; 根蒂=蜷缩)` |
| 特征 / 属性 | 反映对象某方面性质，如「色泽」 |
| 特征向量 | 一个样本的所有属性值构成的向量 $\boldsymbol{x}$ |
| 标签 / 标记 | 样本的「结果」，如「好瓜」 |
| 训练集 / 测试集 | 训练用数据 / 测试泛化能力用数据 |
| 泛化 | 模型适用于新样本的能力 |

### 1.6 过拟合 vs 欠拟合 ⭐⭐⭐
| | 训练误差 | 泛化误差 | 原因 | 缓解 |
|---|---|---|---|---|
| **过拟合** | 小 | 大 | 模型太复杂，学到了噪声 | 正则化、剪枝、增加数据、Dropout、早停、集成 |
| **欠拟合** | 大 | 大 | 模型太简单，能力不足 | 增加模型复杂度、增加特征、减小正则化 |

> 过拟合**无法彻底避免，只能缓解**。

### 1.7 模型评估方法
- **留出法**：直接划分训练集 + 测试集（需分层采样，多次划分取平均）。
- **k 折交叉验证**：分 k 份，轮流 k-1 份训练、1 份测试，取平均（常用 k=10）。
- **自助法 (bootstrap)**：有放回抽样 m 次，约 63.2% 样本出现过，未出现的作测试集（包外估计 OOB）；样本始终不被采到的概率 $(1-1/m)^m\to 1/e\approx 0.368$。

### 1.8 偏差-方差分解 ⭐⭐
$$泛化误差 = 方差 + 偏差^2 + 噪声$$
- **偏差**：模型拟合能力不足 → 训练不足时偏差主导。
- **方差**：对数据扰动敏感 → 训练加深后方差主导，出现过拟合。

### 1.9 习题
**例 1（简答）** 简述过拟合和欠拟合的区别及缓解方法。
> 过拟合：训练误差小、泛化误差大，模型过于复杂学到了噪声；缓解：正则化、剪枝、增加数据、早停。欠拟合：训练和泛化误差都大，模型过于简单；缓解：增加模型复杂度、增加特征、减小正则化。

# 第 2 章 逻辑回归

> 以下为 OneNote 笔记原文转录。

## 2.1 梯度下降确定最优解
梯度下降法是用来计算函数最小值的。思路：想象在山顶放了一个球，一松手它就会顺着山坡最陡峭的地方滚落到谷底；若目标函数是**凸函数**，就可以通过此法一步步收敛到谷底，从而实现求解最优解。
（配图：左为凸函数碗状，可收敛到全局最优；右为非凸多峰函数，可能陷入局部极小。）

## 2.2 逻辑回归定义
逻辑回归也称作 logistic 回归分析，是一种**广义的线性回归分析模型**，属于机器学习中的**监督学习**。其推导过程与计算方式类似于回归的过程，但实际上主要是用来解决**二分类问题**（也可以解决多分类问题）。通过给定的 n 组数据（训练集）来训练模型，并在训练结束后对给定的一组或多组数据（测试集）进行分类。其中每一组数据都是由 p 个指标构成。

## 2.3 逻辑回归背景 & 三个目的
1. **逻辑回归背景**：逻辑回归模型是最常用分类模型之一，其模型经常用作**基准模型**，用于衡量其它模型的效果。利用逻辑回归进行分类的主要思想是：根据现有数据对分类边界线建立回归公式，以此进行分类。这里的"回归"一词源于最佳拟合，表示要找到最佳拟合参数集。训练分类器时的做法就是寻找最佳拟合参数，使用的是最优化算法。
2. 逻辑回归主要基于以下三个目的：
   - a) 预测结果等于 1（即坏样本）的概率
   - b) 对结果或预测进行分类
   - c) 评估模型预测的相关概率或风险

## 2.4 优点
1. 简单高效，计算速度快，易于理解和实现，易并行，在大规模数据情况下非常适用；
2. 直接对分类可能性进行建模，无需事先假设数据分布，避免了假设分布不准确所带来的问题；
3. 以概率的形式输出，而非只是 0 和 1 判定，对许多利用概率辅助决策的任务很有用；输出值自然地落在 0 到 1 之间，有概率意义；
4. 具有很好的数学性质，许多现有的数值优化算法都可以用来求最优解，训练速度快；
5. 模型清晰，它拟合出来的参数代表了每一个特征对结果的影响，是一个理解数据的好工具。

## 2.5 缺点
1. 逻辑回归模型对**共线性非常敏感**，当自变量之间存在高度的自相关时，会导致估计的误差膨胀，故需对是否存在共线性进行检验。可采用**方差膨胀因子 (VIF)** 作为是否存在多重共线性的判断标准；
2. 容易**欠拟合**，大多数情况下需要手动进行特征工程，构建组合特征，分类精度可能不高；
3. 本质上是一个线性的分类器，处理不好特征之间相关的情况。

## 2.6 构造函数（Sigmoid 函数）
- 逻辑回归源于一个非常朴素的想法：对于二分类问题，如果样本的输入是一个标量且设置样本的标签值为 1 或者 0，能否直接预测出一个样本属于分类 1 的概率值？
- 因此需要构造一个函数，将 $(-\infty,+\infty)$ 内的实数值变换到区间 $(0,1)$ 上：
  $$f(z)=\frac{1}{1+e^{-z}}$$

## 2.7 Sigmoid 图像 & 对数几率
- Sigmoid 函数 $y=\dfrac{1}{1+e^{-z}}$ 图像：过 $(0,0.5)$，$z>0$ 时 $y>0.5$，$z=0$ 时 $y=0.5$，$z<0$ 时 $y<0.5$。
- （右侧神经元结构：$X \to wx+b \to \sigma(\cdot) \to output$）
- 考虑二分类任务，输出标记 $y\in\{0,1\}$，线性回归产生的预测值 $z=w^Tx+b$ 是实值，需将实值 $z$ 转换成 0/1 值。若将 $y$ 视为样本 $x$ 作为正例的可能性，则 $1-y$ 是其反例可能性，两者比值为 $\dfrac{y}{1-y}$：
  $$y=\frac{1}{1+e^{-z}} \tag{1}$$
  $$y=\frac{1}{1+e^{-(w^Tx+b)}} \tag{2}$$
  $$\ln\frac{y}{1-y}=w^Tx+b \tag{3}$$
- $\dfrac{y}{1-y}$ 称为 **"几率" (odds)**，反映了 $x$ 作为正例的相对可能性；对几率取对数则得到 **"对数几率" (log odds，亦称 logit)**。
- 上述模型就称为 **"对数几率回归" (logistic regression，亦称 logit regression)**。

## 2.8 设置分布函数
设定逻辑回归的条件分布函数为：
$$P(y=1\mid x)=f(w^Tx+b)=h(x)=\frac{1}{1+e^{-(w^Tx+b)}}$$
$$P(y=0\mid x)=1-f(w^Tx+b)=1-h(x)$$
合并为：
$$P(y\mid x,w,b)=(h(x))^y(1-h(x))^{1-y}$$
这实质上是 **0-1 分布的分布律**。

## 2.9 分类规则
- 一个样本属于分类 1 的概率：$P(y=1\mid x)=h(x)$；属于分类 0 的概率：$P(y=0\mid x)=1-h(x)$。
- 样本属于分类 1 和分类 0 概率值比的对数称为**对数似然比**：
  $$\log\frac{p(y=1\mid x)}{p(y=0\mid x)}=\log\frac{h(x)}{1-h(x)}=w^Tx+b$$

## 2.10 说明
- 对数几率回归译成"逻辑回归"(logistic regression)其实并不恰当，因为和"逻辑"(logistic)一词并无关系。对数几率回归名字中带有"回归"二字，但实际却是一种**分类学习方法**。
- 对数几率函数是**任意阶可导的凸函数**。

## 【考点补充】（帮助考试，非笔记原文）

### 2.11 参数估计：极大似然 → 交叉熵 ⭐⭐⭐
给定数据集 $\{(\boldsymbol{x}_i, y_i)\}$，令 $\hat{y}_i = h(\boldsymbol{x}_i) = \sigma(\boldsymbol{w}^T\boldsymbol{x}_i+b)$。似然函数：
$$L(\boldsymbol{w},b)=\prod_{i=1}^m \hat{y}_i^{\,y_i}(1-\hat{y}_i)^{1-y_i}$$
取对数得对数似然，最大化对数似然等价于最小化**交叉熵损失**：
$$J(\boldsymbol{w},b)=-\frac{1}{m}\sum_{i=1}^m\Big[y_i\ln \hat{y}_i + (1-y_i)\ln(1-\hat{y}_i)\Big]$$

### 2.12 梯度下降参数更新 ⭐⭐
对 $J$ 求 $\boldsymbol{w}$ 的梯度（利用 $\sigma'(z)=\sigma(z)(1-\sigma(z))$）：
$$\frac{\partial J}{\partial \boldsymbol{w}}=\frac{1}{m}\sum_{i=1}^m (\hat{y}_i - y_i)\boldsymbol{x}_i$$
更新：$\boldsymbol{w} \leftarrow \boldsymbol{w} - \eta \dfrac{\partial J}{\partial \boldsymbol{w}}$，$b \leftarrow b - \eta \dfrac{1}{m}\sum(\hat{y}_i-y_i)$，其中 $\eta$ 为学习率。

### 2.13 多分类
- **一对一 (OvO)**：两两配对，共 $N(N-1)/2$ 个分类器。
- **一对其余 (OvR)**：每次一类为正、其余为负，共 $N$ 个分类器。
- 笔记中提到：「如果有 n 类，需要分类 n-1 次」对应 OvR 思路。

# 第 3 章 决策树

> 以下为 OneNote 笔记原文转录。

## 3.1 决策树定义
- 决策论中，**决策树 (Decision tree)** 由一个决策图和可能的结果组成，用来创建到达目标的规划，是一种特殊的树结构。
- 机器学习视角：决策树是一种**非参数的监督学习方法**，通过对训练集数据的学习，挖掘出一定的规则用于对新的数据集进行预测。
- 可将决策树理解为一个 **if-then 决策规则的集合**：从根节点到每个叶子节点的路径对应一条规则，内部节点的特征对应规则的条件，叶子节点对应决策结果。
- 构建决策树的目的：使分支节点所包含的样本尽可能属于同一类别。学习算法一般通过**递归选择最优特征**，并利用该特征对训练集进行分割。

## 3.2 优缺点
**(1) 优点**：① 速度快 ② 准确性高 ③ 可以处理连续字段和种类字段 ④ 不需要任何领域知识和参数假设 ⑤ 适合高维数据
**(2) 缺点**：① 容易过拟合 ② 忽略属性之间的相关性 ③ 各类别样本数量不一致的数据，特征选择偏向于取值较多的特征

## 3.3 特征选择
常用的特征选择准则有：**信息增益、信息增益率、基尼系数**等。

## 3.4 熵（信息熵）
- 熵表示信息的**混乱程度**：信息越有序，信息熵越低。
- 数据集 $D$ 的熵：
  $$H(D)=-\sum_{i=1}^{n} p_i\log_2 p_i$$
- $p_i=\dfrac{|C_i|}{|D|}$；注意前面的负号；$n$ 为标签数；对数可以 2 或 $e$ 为底。

## 3.5 条件熵
$$H(D\mid A)=-\sum_{i=1}^{n}\frac{|D_i|}{|D|}\left(\sum_{k=1}^{K}\frac{|D_{ik}|}{|D_i|}\log_2\frac{|D_{ik}|}{|D_i|}\right)$$
- $D_i$：$D$ 中特征 $A$ 取第 $i$ 个值的样本子集；$D_{ik}$：$D_i$ 中属于第 $k$ 类的样本子集。

## 3.6 ID3 算法（基于信息增益）
- ID3 基于**信息增益**，选取信息增益最大的特征。
- **信息增益**：$g(D,A)=H(D)-H(D\mid A)$
- **算法流程**：① 给定样本集 $D$ 及特征集 $A$；② 计算 $H(D)$；③ 对每个特征求 $H(D\mid A_i)$ 及 $g(D,A_i)$；④ 选信息增益最大的特征划分。
- **不足**：偏向**取值较多的特征**（取值多→条件熵低→信息增益大）。

## 3.7 C4.5 算法（基于信息增益率）
- 引入**信息增益率**，取最大者作为分裂节点：
  $$g_R(D,A)=\frac{g(D,A)}{H_A(D)},\quad H_A(D)=-\sum_{i=1}^{n}\frac{|D_i|}{|D|}\log_2\frac{|D_i|}{|D|}$$
- $H_A(D)$ 是特征 $A$ 的取值熵（固有值），对取值多的特征进行惩罚。

## 3.8 CART 算法（基于基尼指数）
- CART 既可用于**回归**又可用于**分类**，构建**二叉树**，进行二值划分，能处理离散和连续数据。
- **基尼指数描述数据的纯度**：基尼指数越小，纯度越高。
- **Gini 定义**：
  $$Gini(p)=\sum_{k=1}^{K}p_k(1-p_k)=1-\sum_{k=1}^{K}p_k^2,\qquad p_k=\frac{|C_k|}{|D|}$$
- **二分类**时（属于第 1 类概率为 $p$）：
  $$Gini(p)=2p(1-p)$$
  （答题模板：二分类基尼指数公式 $2p(1-p)$）
- **特征 $A$ 的基尼指数**（按是否取某值 $a$ 二分）：
  $$Gini(D\mid A)=\frac{|D_1|}{|D|}Gini(D_1)+\frac{|D_2|}{|D|}Gini(D_2)$$
- 选择**最小基尼指数**作为划分标准。

## 3.9 CART 对连续变量的处理
将连续特征值离散化。设特征 $a$ 有 $m$ 个连续值从小到大排列，共 $m-1$ 个切分点（相邻值中点），计算每个切分点下的 Gini 系数，选 Gini 最小的作为最终划分。
- 划分1：$\{a_1\}\mid\{a_2,\dots,a_m\}$，切分点 $\dfrac{a_1+a_2}{2}$；……

## 3.10 CART 算法流程
- **输入**：数据集 $D$，特征集 $A$，停止条件阈值 $\epsilon$
- 1. 从根节点构建二叉树；2. 计算各特征的基尼指数，选最优特征与最优切分点（基尼最小）；3. 生成两个子结点，分配训练集；4. 递归直至满足停止条件（结点样本数过小、基尼过小、或无更多特征）。

# 第 4 章 支持向量机 (SVM)

> 以下为 OneNote 笔记原文转录。

## 4.1 SVM 定义
在机器学习中，**支持向量机（Support Vector Machine，SVM，又名支持向量网络）** 是在分类与回归分析中分析数据的**监督式学习模型**与相关的学习算法。给定一组训练实例，每个被标记为属于两个类别之一，SVM 建立一个将新实例分配给两个类别之一的模型，是**非概率二元线性分类器**。SVM 模型将实例映射到空间中，使得单独类别的实例被尽可能宽的间隔分开；再将新实例映射到同一空间，依据落在间隔哪一侧预测类别。除线性分类外，SVM 还可用**核技巧**将输入隐式映射到高维特征空间进行非线性分类。

## 4.2 SVM 的目标
- 目的：找到集合边缘上的若干数据（**支持向量**），用这些点找出一个平面（**决策面/分离超平面**），使**支持向量到该平面的距离最大**（最大间隔 Maximum Margin）。
- （图：分界线 $\theta_0+\theta_1x_1+\theta_2x_2=0$，两侧 $\pm1$，支持向量位于间隔边界。）

## 4.3 优缺点
**优点**：
① 计算复杂度取决于**支持向量的数目**而非样本空间维数，某种意义上避免了"维数灾难"；
② 可以处理线性不可分；
③ 可实现对特征空间划分的**最优超平面**；
④ 避开了从归纳到演绎的传统过程，实现了从训练样本到预报样本的高效"**转导推理**"；
⑤ 抓住关键样本、剔除冗余样本，"鲁棒"性好，增删非支持向量样本对模型无影响。

**缺点**：
① 对大规模训练样本难以实施，样本量大时矩阵存储和计算耗费大量内存与时间；
② 解决多分类问题存在困难。

## 4.4 分类：硬间隔与软间隔
- 数据完全线性可分 → **硬间隔**支持向量机：完全分类准确，不允许分类错误。
- **软间隔**：允许一定量的样本分类错误。
- （图：线性可分 / 硬间隔 / 软间隔 / 线性不可分。）

## 4.5 线性可分 SVM
- 不只有一条直线可分开样本，要找使两类中距直线最近的异类样本点"间隔"最大的直线。
- 点距分离超平面的远近可表示分类预测的**确信度**，故 SVM 目标是找一个超平面，使离它近的异类点间间隔最大（不必考虑所有样本点）。
- 中间那条直线对训练样本扰动"容忍性"最好，对未见样本**泛化能力最强**（受噪声影响最小）。

## 4.6 逻辑回归 vs SVM
- 逻辑回归尽可能**提高所有点分类正确的概率**（尝试将所有点都远离边界）；
- SVM 尝试**最大化由支持向量确定的边界距离**（把支持向量推得更开）。

## 4.7 线性不可分 SVM
不能线性分类时考虑非线性问题，采用**非线性变换**将非线性问题变成线性问题。
（图：二维环形数据线性不可分，升到三维后可用平面分开。）

## 4.8 核函数
**核函数**将样本从原始空间映射到更高维特征空间，使样本在新空间**线性可分**，可沿用原来的推导，只是在新空间计算。
（图：二维环形数据增加 $z=x^2+y^2$ 维度后三维线性可分。）

## 【考点补充】（帮助考试，非笔记原文）

### 4.9 间隔与支持向量（数学）⭐⭐⭐
- 划分超平面：$\boldsymbol{w}^T\boldsymbol{x}+b=0$；样本到超平面距离 $r=\dfrac{|\boldsymbol{w}^T\boldsymbol{x}+b|}{\|\boldsymbol{w}\|}$。
- 二分类 $y_i\in\{+1,-1\}$，约束：$y_i(\boldsymbol{w}^T\boldsymbol{x}_i+b)\ge 1$。
- **间隔** = $\dfrac{2}{\|\boldsymbol{w}\|}$；**支持向量** = 使等号成立的样本，决定超平面。
- 间隔最大化：$\max\dfrac{2}{\|\boldsymbol{w}\|} \iff \min\dfrac{1}{2}\|\boldsymbol{w}\|^2$。

### 4.10 对偶问题与 KKT ⭐⭐⭐
原问题：
$$\min_{\boldsymbol{w},b}\ \frac{1}{2}\|\boldsymbol{w}\|^2 \quad \text{s.t.}\ y_i(\boldsymbol{w}^T\boldsymbol{x}_i+b)\ge 1$$
引入拉格朗日乘子 $\alpha_i\ge 0$，KKT 条件：$\alpha_i(1-y_i(\boldsymbol{w}^T\boldsymbol{x}_i+b))=0$。
- **结论**：训练完成后只有**支持向量的 $\alpha_i>0$**，非支持向量 $\alpha_i=0$，模型只依赖支持向量。
- 求得 $\boldsymbol{\alpha}$ 后：$\boldsymbol{w}=\sum \alpha_i y_i \boldsymbol{x}_i$，预测 $f(\boldsymbol{x})=\text{sign}(\sum \alpha_i y_i \boldsymbol{x}_i^T\boldsymbol{x}+b)$。
- 用 **SMO 算法**高效求解。

### 4.11 软间隔与正则化 ⭐⭐
允许某些样本不满足约束，引入松弛变量 $\xi_i$：
$$\min \frac{1}{2}\|\boldsymbol{w}\|^2 + C\sum_{i=1}^m \xi_i \quad \text{s.t.}\ y_i(\boldsymbol{w}^T\boldsymbol{x}_i+b)\ge 1-\xi_i,\ \xi_i\ge 0$$
- $C$ 为惩罚参数：$C$ 越大对误分类惩罚越重，越接近硬间隔，越易过拟合；$C\to\infty$ 退化为硬间隔。

### 4.12 常用核函数 ⭐⭐
| 核函数 | 表达式 |
|---|---|
| 线性核 | $\kappa(\boldsymbol{x}_i,\boldsymbol{x}_j)=\boldsymbol{x}_i^T\boldsymbol{x}_j$ |
| 多项式核 | $\kappa=(\boldsymbol{x}_i^T\boldsymbol{x}_j)^d$ |
| 高斯核 (RBF) | $\kappa=\exp(-\frac{\|\boldsymbol{x}_i-\boldsymbol{x}_j\|^2}{2\sigma^2})$ |
| Sigmoid 核 | $\kappa=\tanh(\beta \boldsymbol{x}_i^T\boldsymbol{x}_j+\theta)$ |

**例 3（简答）** 什么是核函数？它在 SVM 中起什么作用？

# 第 5 章 集成学习算法

> 以下为 OneNote 笔记原文转录。

## 5.1 集成学习理论起源
集成理论最早起源于 **Kearns and Valiant (1989)** 提出的**强学习和弱学习的等价原理**，核心思想是：将多个分类器模型组合在一起，得到一个具有更好泛化能力的**强学习器模型**。也可把集成学习看成将不同专家的决定通过一定方法融合为一个结果，使多个专家判断更具权威性。常用融合方法是**平均法**和**投票法**。

## 5.2 为什么需要集成（以决策树为例）
决策树构建复杂，数据干扰时对树生成影响大（如过拟合）。单个决策树极不稳定，常达到**局部最优**，难达**全局最优**。因此应采用**集成思想**，用多个分类器，最后综合每个分类器的结果。

## 5.3 集成算法三类
- ① **Bagging**：从数据集中多次重复（有放回）采样，独立训练多个分类器，再**投票**得到结果最多的分类。代表：**随机森林**。
- ② **Boosting**：不断构建新模型，新模型更关注前一个模型中被错分的样本，最终对结果**加权组合**。代表：**AdaBoost、GBDT、XGBoost**。
- ③ **Stacking**：不常用，属于**分层的集成学习框架**，在形成最终预测前，从一组学习器向另一组学习器提供信息。

## 5.4 随机森林 (Random Forest)
基于**决策树、随机子空间和 Bagging** 思想的算法，由多棵决策树组成强分类器；"随机"体现在每棵树生成过程中**样本和特征都随机选取**。

### 建模步骤
1. 随机选择样本（放回抽样 / Bootstrap）
2. 随机选择特征
3. 构建决策树，重复 1–3 步 n 次，产生 n 棵决策树
4. 投票（分类）/ 平均（回归）

（流程：原始数据集 → Bootstrap 抽样（约抽 2/3）→ 多个训练集 → 生成 CART 决策树（特征抽样 + 最优分割）→ 对剩余约 1/3 数据（袋外 OOB）作测试并计算 OOB 误差 → 投票/均值得最终结果。）

### 优缺点
**优点**：① 能解决分类与回归，泛化性能优越；② 处理高维数据好，能输出**特征重要性**，是不错的降维方法；③ 可应对缺失数据，不需归一化；④ 分类不平衡时能平衡误差；⑤ 训练快，**高度并行化**。
**缺点**：① 回归时不能给出连续型输出，不能超越训练集范围预测，特定噪声下可能过拟合；② 无法控制模型内部运行；③ 忽略特征间相关性，可能产生很多相似树。

## 5.5 GBDT（梯度提升决策树）
属于 Boosting 算法，利用**损失函数的负梯度方向**在当前模型的值作为**残差的近似值**，拟合一棵 **CART 回归树**。每次训练目的是减少上一次的残差，本轮目标是找到一个 CART 回归树弱学习器使损失最小。

### 优缺点
**优点**：① 可处理离散值和连续值；② 调参时间短；③ 预测准确率较高；④ 损失函数多，对异常值鲁棒性强。
**缺点**：① 梯度方向未做到最优步长；② 有过拟合风险；③ 数据维度高时计算复杂度大。

### 损失函数
常用**均方差损失函数**：$l(y_i,f(x_i))=\dfrac{1}{2}(y_i-f(x_i))^2$。

## 5.6 XGBoost
### 定义
极度提升树（eXtreme Gradient Boosting），基于决策树的**分布式高效梯度提升算法**，集成多个基学习器（CART 回归树、线性分类器）形成强学习器。

### 基本思想
① 许多弱分类器组合成强分类器：最终预测值为所有树预测值的**加权和**；② 不断在错误中学习，用迭代降低犯错概率，采用 GBDT 基于残差建模的思想。

### 核心思想
通过迭代**增加树**，每次添加的树都在拟合上次预测的**残差**。预测时样本在每棵树落到对应叶子节点，每个叶子节点对应一个分数，分数相加得预测值。

### 优缺点
**优点**：① 对输入不敏感，可有缺失值；② 不需特征归一化；③ 可自动特征选择；④ 并行处理，速度和准确率较 GBDT 明显提升且复杂度不高。
**缺点**：① 参数过多；② 不适合超高维特征数据；③ 模型解释性不好。

### XGBoost 比 GBDT 优化了哪些
① 目标函数**增加正则项**防过拟合；② 利用损失函数关于预测函数的**二阶导数**，增加可利用信息量；③ 对节点分裂、数据处理、并行计算、内存读取等进一步优化集成，是集大成者。

### 5.7 AdaBoost 算法 ⭐⭐⭐
1. 初始化样本权重 $\mathcal{D}_1(i)=1/m$；
2. 第 $t$ 轮在 $\mathcal{D}_t$ 下训练基学习器 $h_t$；
3. 错误率 $\epsilon_t=\sum \mathcal{D}_t(i)\mathbb{I}(h_t(\boldsymbol{x}_i)\neq y_i)$，若 $\epsilon_t>0.5$ 停止；
4. 学习器权重 $\alpha_t=\dfrac{1}{2}\ln\dfrac{1-\epsilon_t}{\epsilon_t}$；
5. 更新样本权重：错分样本权重放大，正确样本缩小；
6. 最终 $H(\boldsymbol{x})=\text{sign}\big(\sum_t \alpha_t h_t(\boldsymbol{x})\big)$。

### 5.8 Bagging vs Boosting 对比 ⭐⭐⭐
| 维度 | Bagging | Boosting |
|---|---|---|
| 依赖关系 | 独立，可**并行** | 串行，强依赖 |
| 样本权重 | 均匀（bootstrap 采样） | 动态调整（错分加权） |
| 基学习器权重 | 相同（多数投票） | 不同（按错误率加权） |
| 主要作用 | 降低**方差** | 降低**偏差** |
| 适用基学习器 | 高方差（深树） | 高偏差（浅树/决策树桩） |
| 代表 | 随机森林 | AdaBoost、GBDT、XGBoost |

### 5.9 结合策略
- 平均法（简单/加权平均）→ 回归；投票法（绝对多数/相对多数/加权）→ 分类；学习法 Stacking → 通用。

### 5.10 习题

> $\alpha_1=\frac{1}{2}\ln\frac{1-0.3}{0.3}=\frac{1}{2}\ln\frac{7}{3}\approx 0.424$。

**例 2（判断）** 随机森林只能用决策树作为基学习器。（ ）
> √。随机森林是 Bagging + 随机属性选择的决策树集成。

**例 3（简答）** 随机森林的"随机"体现在哪里？OOB 是什么？
> 随机体现在：① 样本扰动（Bootstrap 有放回采样）；② 属性扰动（每个结点随机选部分特征再选最优划分）。OOB（袋外数据）= Bootstrap 采样中未被抽到的约 36.8% 样本，可用来估计泛化误差（包外估计），无需额外划分验证集。

**例 4（简答）** GBDT 和 XGBoost 的区别？
> XGBoost 在 GBDT 基础上：① 目标函数加了正则项（树复杂度）防过拟合；② 用二阶泰勒展开（二阶导数）近似损失，收敛更快更准；③ 支持并行、缺失值自动处理、特征重要性输出；④ 工程优化（缓存、块结构）。

# 第 6 章 聚类

> 以下为 OneNote 笔记原文转录。

## 6.1 聚类的定义
聚类就是把对象按一定规则分成若干类，这些类**不是事先给定的**，而是根据数据特征确定的，对类的数目和结构不必作任何假设。"物以类聚、人以群分"——同一类里对象倾向于彼此**相似**，不同类里的对象倾向于**不相似**。

## 6.2 聚类分析的三个重要原则
① **同质性原则**：同一类中个体之间有较大相似性 → 保证类别之内的共性；
② **互斥性原则**：不同类中的个体差异很大 → 保证类别之间的差异性；
③ **完备性原则**：每个个体在同一次分类中能且只能分在一个类别 → 每个个体都应被包含，且不能同时属于不同类别。

## 6.3 层次聚类（谱系聚类）
### 定义
以一定分类规则作为**类与类之间的距离**（类间距离）进行聚类。
### 基本思想
聚类前所有个体各自独树一帜、自成一类。根据个体间距离聚类：先把**距离最近**的个体聚为同类，再据最短距离继续扩大类别范围，直到所有个体聚为 1 个大类（自底向上凝聚）。
### 谱系图
描述分类过程的图形称为**谱系聚类图**，简称谱系图，故层次聚类又称**谱系聚类**。
（流程：计算距离 → 每个个体合成一类 → 把最近两类合为新类 → 计算距离 → 若仅有一类则停止，据谱系图定类数。）

## 6.4 K-means 聚类
### 定义
K-means 是一种流行的**动态聚类法**，是**无监督**分类算法，试图找到使**平方误差函数最小**的簇。
### 优缺点
**优点**：① 适用于大数据集，数据量越大越显优越性；② 处理大数据集高效，伸缩性好。
**缺点**：① 需**事先确定簇数 K**；② 对**初始聚类中心敏感**；③ 经常以**局部最优**结束；④ 对**噪声点和孤立点敏感**。
### 基本原理
选择一批凝聚点（种子），让样本按某种规则向种子点凝聚，不断修改或迭代凝聚点，直至分类合理或迭代稳定。类数可事先指定或在聚类中确定。初始凝聚点的简单选法是**随机抽选（或随机分割）样本**。

## 【考点补充】（帮助考试，非笔记原文）

### 6.5 K-means 算法步骤 ⭐⭐⭐
1. 随机选 $k$ 个样本作为初始均值向量 $\{\boldsymbol{\mu}_1,\dots,\boldsymbol{\mu}_k\}$；
2. 每个样本归入距离最近的均值向量所在簇；
3. 对每个簇重新计算均值：$\boldsymbol{\mu}_j=\dfrac{1}{|C_j|}\sum_{\boldsymbol{x}\in C_j}\boldsymbol{x}$；
4. 重复 2–3 直到均值向量不再变化（或达最大迭代）。
- 目标：最小化平方误差 $E=\sum_{i=1}^k\sum_{\boldsymbol{x}\in C_i}\|\boldsymbol{x}-\boldsymbol{\mu}_i\|^2$。

### 6.6 距离度量 ⭐⭐
闵可夫斯基距离：$\text{dist}(\boldsymbol{x}_i,\boldsymbol{x}_j)=(\sum_u |x_{iu}-x_{ju}|^p)^{1/p}$
- $p=1$ 曼哈顿距离；$p=2$ 欧氏距离；$p\to\infty$ 切比雪夫距离。

### 6.7 K 值选择与改进
- **肘部法 (Elbow)**：画 SSE 随 $k$ 变化曲线，找拐点。
- **轮廓系数法**：选轮廓系数最大的 $k$。
- 改进：K-Means++（优化初始化）、K-Medoids（用真实样本作中心，抗噪）、二分 K-Means。

### 6.8 密度聚类 DBSCAN ⭐⭐
- **核心对象**：$\epsilon$-邻域内样本数 $\ge$ MinPts；**噪声点**：不在任何簇中。
- 能发现**任意形状簇**、自动识别噪声、不需指定簇数；但对 $\epsilon$、MinPts 敏感。

### 6.9 习题
**例 1（计算）** 5 个一维样本：$1,2,3,6,7$，$k=2$，初始中心 $\mu_1=1,\mu_2=2$。给出第一次迭代后的簇划分和新中心。
> 到 $\mu_1=1$ 距离：$0,1,2,5,6$；到 $\mu_2=2$ 距离：$1,0,1,4,5$。
> 分配：$1\to C_1$；$2,3,6,7\to C_2$（3 距 1、2 相等，归 $\mu_2$）。
> 新中心：$\mu_1=1$，$\mu_2=(2+3+6+7)/4=4.5$。（下一轮最终收敛到 $\{1,2,3\}$ 和 $\{6,7\}$。）

**例 2（简答）** K-Means 和 DBSCAN 的区别？
> K-Means 基于原型（均值），只能发现球状簇，需指定 $k$，对噪声敏感；DBSCAN 基于密度，能发现任意形状簇、自动识别噪声、不需指定簇数，但对参数 $\epsilon$、MinPts 敏感。

**例 3（判断）** K-means 对初始聚类中心不敏感，总能得到全局最优。（ ）
> ×。K-means 对初始中心敏感，常以局部最优结束。

**例 4（简答）** 层次聚类的基本思想？为什么又称谱系聚类？
> 自底向上：初始每个样本自成一类，每次合并距离最近的两类，直到满足终止条件。描述该合并过程的树状图称为谱系图，故层次聚类又称谱系聚类。

# 第 7 章 特征工程与评估指标

> 以下为 OneNote 笔记原文转录。

## 7.1 特征工程定义
特征工程是从**原始数据转换为特征向量**的过程，是机器学习最重要的起始步骤，直接影响学习效果，通常需要大量时间。典型过程包括**数据清理、特征提取、特征选择**。

### 定义 / 目的 / 作用 / 构成
- **定义**：把原始数据转变为模型的训练数据的过程。
- **目的**：获取更好的训练数据特征，使模型逼近性能上限。
- **作用**：提升模型性能。
- **构成**：特征构建；特征提取；特征选择。

### 重要性
各种算法在数据量达到一定级数后都有相近的高准确度。机器学习界名言：**成功的机器学习应用不是拥有最好的算法，而是拥有最多的数据，数据决定一切。**

## 7.2 特征构建
**定义**：人工找出具有物理意义的特征；当原特征不适合直接建模时，构造新特征可能更有效。
**方法**：经验、属性分割和结合。
**数据标准化**：使不同规格数据转换到同一规格，让不同特征具备可比性；标准化后**数据分布不改变**。
- ① 归一化（最大-最小规范化）；② Z-Score 标准化。

### ① 归一化（最大-最小规范化）
映射到 $[0,1]$：$x_{new}=\dfrac{x-x_{min}}{x_{max}-x_{min}}$。使各特征对目标变量影响一致，**会改变**数据分布。

### ② Z-Score 标准化
处理后均值为 0、方差为 1：$Z=\dfrac{x-\mu}{\sigma}$（$\mu$ 均值，$\sigma$ 标准差）。

### 分箱
建立分类模型时常需对连续变量**离散化**，离散化后模型更稳定，降低过拟合风险。

### 聚合特征构造
对多个特征分组聚合（来自同表或多表联立），统计量如中位数、均值、众数、最值、标准差、方差、频数等。

### 转换特征构造
用单一或多个特征变换结果作新特征，方法有单调转换（幂、log、绝对值）、线性组合、多项式组合比例等。例：单价×销售量=销售额；原价−售价=利润。

## 7.3 特征提取
**定义**：自动构建新特征，将原始数据转换为一组有明显物理意义（几何、纹理）或统计意义的特征。
**降维**：
- ① **PCA（主成分分析）**：找数据中的主成分，用主成分表征原始数据，达到降维目的（**压缩信息**）。
- ② **ICA（独立成分分析）**：获得相互独立的属性（**分离信息**，常先应用 PCA 更有益）。
- 两者预处理都需要 autoscaling（自动缩放/标准化）。

## 7.4 特征选择
**定义**：从给定特征集合中选出相关特征子集的过程。
**目的**：降低学习难度、简化模型、降低计算复杂度、确保不丢失重要特征。
**方法**：
- ① **过滤式 (Filter)**：先选特征再训练，与后续学习器无关。→ 高效、对过拟合稳健；但倾向选冗余特征（未考虑特征间相关性）。
- ② **包裹式 (Wrapper)**：直接用最终学习器的性能评价特征子集。→ 性能好、考虑特征关联性；但计算开销大。
- ③ **嵌入式 (Embedded)**：特征选择与训练融为一体，训练中自动选择（如决策树、随机森林）。

## 7.5 评估指标：混淆矩阵
| | 真实值 Positive | 真实值 Negative |
|---|---|---|
| **预测值 Positive** | TP (True Positive) ✓ | FP (False Positive) ✗ |
| **预测值 Negative** | FN (False Negative) ✗ | TN (True Negative) ✓ |

**期望**：TP 和 TN 越大越好，FN 和 FP 越小越好。

### 四大指标
- **准确率 (Accuracy)** $=\dfrac{TP+TN}{TP+TN+FP+FN}$；缺陷：类别不均衡时占比大类主导，不足以说明分类器好坏。
- **精确度 (Precision)** $=\dfrac{TP}{TP+FP}$；预测为正且实际为正的比例，决定模型是否可靠。
- **召回率 (Recall)** $=\dfrac{TP}{TP+FN}$；实际为正中被预测为正的比例。
- **F1 分数** $=2\times\dfrac{P\times R}{P+R}$；P 与 R 的调和平均，平衡两者；当 $P=R$ 时 F1 最大。

## 【考点补充】（帮助考试，非笔记原文）

### 7.6 ROC 与 AUC ⭐⭐⭐
- **ROC 曲线**：横轴 = 假正例率 $FPR=\dfrac{FP}{FP+TN}$，纵轴 = 真正例率 $TPR=\dfrac{TP}{TP+FN}$（即 Recall）。改变分类阈值得到曲线。
- **AUC**：ROC 曲线下面积，$AUC\in[0.5,1]$，**越接近 1 越好**，0.5 相当于随机猜测。
- AUC 物理意义：随机抽一个正例和一个反例，模型将正例排在反例前面的概率。

### 7.7 $F_\beta$ 分数
$$F_\beta=\frac{(1+\beta^2)\times P\times R}{\beta^2\times P+R}$$
$\beta>1$ 召回率影响更大；$\beta<1$ 精确率影响更大；$\beta=1$ 即 F1。

### 7.8 归一化 vs 标准化 ⭐⭐
| | 归一化 (Min-Max) | 标准化 (Z-Score) |
|---|---|---|
| 输出范围 | $[0,1]$ | 均值 0、方差 1 |
| 是否改变分布 | 改变（伸缩） | 不改变分布形状 |
| 适用 | 有界、量纲不一、对范围敏感 | 数据近似正态、异常值较多 |
| 缺点 | 受异常值影响大 | — |

### 7.9 习题
**例 1（计算）** 100 个样本，真实正例 60 个，模型预测为正的有 50 个，其中真正例 40 个。求精确率、召回率、F1。
> TP=40，FP=10，FN=20，TN=30。$P=40/50=0.8$，$R=40/60\approx0.667$，$F1=2\times0.8\times0.667/(0.8+0.667)\approx0.727$。

**例 2（判断）** AUC 值越接近 0.5，说明分类器性能越好。（ ）
> ×。AUC 越接近 1 越好，0.5 是随机水平。

**例 3（简答）** 比较过滤式、包裹式、嵌入式特征选择。
> 过滤式先按准则筛特征再训练，速度快但未考虑学习器；包裹式直接用学习器性能评价特征子集，效果好但开销大；嵌入式在训练中同时选择（如 L1 正则、决策树），兼顾效率与效果。

**例 4（简答）** 准确率有什么缺陷？什么时候用精确率/召回率/F1？
> 准确率在类别不均衡时会被占比大类主导（如罕见病全判负也有 99% 准确率）。当关注"预测为正的有多可靠"用精确率，关注"实际正例找回多少"用召回率，需平衡两者用 F1；综合排序能力用 AUC。

**例 5（判断）** 标准化会改变特征数据的分布形状。（ ）
> ×。笔记明确：标准化变换后数据分布没有发生改变；改变分布的是归一化。

# 附录 C 答题技巧与考前提醒

## 1️⃣ 计算题套路
- **信息增益 / 基尼指数**：算原熵 → 算各划分后熵 → 按样本比例加权求和 → 相减（增益）或取最小（基尼）。⚠️ 注意用 $\log_2$；二分类基尼直接套 $2p(1-p)$。
- **线性回归最小二乘**：单变量套 $w=\dfrac{\sum y_i(x_i-\bar{x})}{\sum(x_i-\bar{x})^2}$，$b=\bar{y}-w\bar{x}$。
- **混淆矩阵 / P / R / F1**：先列出 TP/FP/FN/TN 四个数，再套公式。
- **AdaBoost 权重**：$\alpha_t=\frac12\ln\frac{1-\epsilon_t}{\epsilon_t}$；错分样本权重放大。
- **K-means 迭代**：算距离 → 分配簇 → 更新均值，直到不变。
- **PCA**：中心化 → 协方差矩阵 → 特征分解 → 选大特征值向量 → 投影。

## 4️⃣ 选择题高频陷阱
