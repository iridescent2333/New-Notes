# 四科训练与复盘

[返回总览](../README.md)

共用训练回路：**先独立作答 → 核对依据 → 记一个错误原因 → 隔日闭卷重做 → 换一道变式。** 可以先试 1、3、7、14 天回看，按遗忘与难度调整。把 AI 当作答疑和出变式的助手，原始标准由大纲、真题及正式资料锚定。训练重点放在提取练习和分散练习。[Dunlosky 等综述](https://journals.sagepub.com/stoken/rbtfl/Z10jaVH/60XQM/full)

## 数学一

- **基础**：高数按极限与连续、导数微分、积分与应用、多元、级数及微分方程推进；线代按矩阵、线性空间与方程组、特征值、二次型；概率按条件概率、分布、数字特征、大数与中心极限定理及数理统计。实际范围逐项对照当年大纲。
- **每天 90 分钟写法**：20 分钟闭卷回忆定义和适用条件，55 分钟完整演算，15 分钟审计卡在哪。先复写典型错题再看新题讲解。针对难以启动的证明，先写出已知条件能推出什么。
- **强化**：题按识别、推导、计算三层处理。每周加一组跨章节题，记录一道最可挽回的失分。线代用反例区分“可对角化”“合同”“相似”等容易串线的概念。
- **冲刺**：固定答题顺序和返回点。每周一套整卷，加一个等时段订正。分数波动时统计空题、时间和计算错误，再决定补题型还是练节奏。

## 408

| 模块 | 优先练习 | 用什么验收 |
|---|---|---|
| 数据结构 | 复杂度、链表和树、图遍历、排序、查找 | 先写推演，再用 C/C++ 中一门实现和测边界 |
| 计组 | 表示与运算、存储层次、指令、CPU/流水线、总线和 I/O | 能手算地址划分、时序、性能题并说清条件 |
| 操作系统 | 进程线程、调度、同步、内存、文件和设备 | 手写信号量、页面置换、死锁等过程，再复核 |
| 计网 | 分层、链路、IP 路由与子网、TCP、应用层 | 画报文方向，手算子网、窗口和时延 |

C 指针、结构体和递归每周动手即可，学习数据结构时继续熟悉语法。机器学习、数据库及大数据项目作为复试储备，初试范围从正式大纲确认。暑假前至少做一轮四科混测，每个漏点定位到一题、一章节和下一次复测。初试准备进度允许时，每周另做一次 60–90 分钟机试。

## 英语一与六级

- 六级考前保留听力和限时阅读，同周写一篇，按正确率和错因调整。若已过线但怕掉词汇，采用轻量词本和短阅读维持。
- 考研英语一从阅读入手，每篇保留题干、证据句和干扰项误导方式，先限时作答再精读。分开统计词汇、长难句、逻辑与时间失误。
- 7 月起练翻译、新题型和写作；每周至少一份独立产出，先自查切题、段落、用词，再请 AI 提具体修改。11 月练整卷时间。
- 六级可用 500+ 作阶段练习目标，表现有余量再挑战 550+。免修按入学批次与具体课程核验，详见[六级与培养核查](../02-院校调研/城市校区与培养核查.md)。

## 政治

7 月用每周 3–4 小时打框架，8–9 月 4–5 小时配选择题，10 月起按错题涨到约 5–7 小时。考前用当年材料做主观题闭卷列点和限时书写。每月核对大纲和新材料。连续两次计时练习选择题波动大，先追溯题干关键词误读或知识框架混淆。

## 每周复盘卡

| 只记四项 | 填写 |
|---|---|
| 计划、实际小时 | 数 / 专 / 英 / 政 |
| 一份闭卷证据 | 日期、试卷、用时、未学模块标注 |
| 最大失分与可挽回分 | 哪个步骤、准备怎样改 |
| 下周三个动作 | 指向题号、章节或真实交付 |

保留少量整卷作为未见验证。AI 模拟题只算练习。做过或看过答案的卷注明熟悉度，避免把记熟误当作新的稳定分数。
